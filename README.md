# 메뉴 스캔 주문 📷🍽

메뉴판 사진 한 장으로 시작하는 단체 주문 웹앱입니다.

1. 메뉴판 사진을 올리면 AI(Claude)가 **메뉴와 가격을 표로 변환**합니다.
2. 잘못 읽힌 부분은 **수정 버튼**으로 바로 고칠 수 있습니다.
3. **타이머**를 설정하고 링크를 공유하면, 받은 사람들이 메뉴를 선택합니다.
4. 모두의 주문이 **실시간으로 합산**되어 개인별 금액과 전체 총 금액이 표시됩니다.
5. 타이머가 끝나면 주문이 마감되고 **최종 주문 결과(메뉴별 합계·사람별 내역·총 금액)** 가 표시됩니다. 방 데이터는 자동 정리되며, 호스트는 언제든 **초기화 버튼**으로 수동 초기화할 수 있습니다.

파일 하나(`index.html`)로 된 정적 웹앱이라 GitHub Pages 등 어디에나 올릴 수 있습니다.

---

## 빠른 시작

### 1) 배포 (GitHub Pages)

1. 이 저장소의 **Settings → Pages** 로 이동
2. Source: `Deploy from a branch`, Branch: `main` / `(root)` 선택 후 저장
3. 잠시 후 `https://<계정명>.github.io/menu/` 주소로 접속

로컬에서 테스트하려면:

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

### 2) 사진 → 메뉴 변환용 API 키

두 가지 중 하나를 앱 상단 **⚙️ 연결 설정**에 넣으면 됩니다. (키는 브라우저 localStorage에만 저장되며, 사진을 올리는 호스트에게만 필요합니다)

**A. Google Gemini — 무료 (추천)**

1. https://aistudio.google.com/apikey 접속 → 구글 계정 로그인
2. **"API 키 만들기(Create API key)"** 클릭 → `AIza...`로 시작하는 키 복사
3. 앱의 ⚙️ 연결 설정 → **Google Gemini API 키**에 붙여넣고 저장

무료 할당량(분당/일일 요청 제한)이 있지만 점심 주문 용도로는 충분합니다. 결제 등록이 필요 없습니다.

**B. Anthropic Claude — 유료·고정밀**

1. https://platform.claude.com 에서 크레딧 충전($5~) 후 API 키 발급
2. 앱의 ⚙️ 연결 설정 → **Anthropic API 키**에 붙여넣고 저장

두 키가 모두 있으면 "사진 분석 엔진" 설정에서 선택할 수 있고, 자동 모드에서는 무료인 Gemini를 우선 사용합니다.

> API 키가 전혀 없어도 "메뉴 직접 추가" 버튼으로 수동 입력해 사용할 수 있습니다.

### 3) Firebase 설정 (주문 공유 · 실시간 합산)

**기본 Firebase 설정이 `index.html`에 내장되어 있어 별도 설정 없이 바로 사용할 수 있습니다.** 호스트도 참여자도 링크만 열면 됩니다. (웹 config는 공개되어도 되는 값이며, 접근 제어는 데이터베이스 규칙이 담당합니다)

다른 Firebase 프로젝트를 쓰고 싶은 경우에만 아래 절차를 따르세요. 무료 요금제(Spark)로 충분합니다.

1. https://console.firebase.google.com 에서 **프로젝트 추가**
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기** (테스트 모드로 시작)
3. **프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹 앱 추가(</>)** 후 표시되는 `firebaseConfig` 객체를 복사
4. 앱의 **⚙️ 연결 설정 → Firebase 설정**에 붙여넣고 저장 (개별 브라우저에 저장한 설정이 내장 설정보다 우선합니다), 또는 `index.html`의 `BUILTIN_FB_CONFIG` 상수를 교체

붙여넣는 형식 예시:

```js
{
  apiKey: "AIza...",
  authDomain: "myapp.firebaseapp.com",
  databaseURL: "https://myapp-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId: "myapp",
  appId: "1:1234:web:abcd"
}
```

데이터베이스 **규칙**은 간단히 아래처럼 두면 됩니다 (테스트/소규모 사용 기준):

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

> Firebase 연결이 불가능한 환경(내장 설정 삭제 등)에서는 **로컬 모드**로 동작합니다. 이 기기에서만 주문이 기록되며 링크 공유 합산은 되지 않습니다.

## 사용 흐름

| 역할 | 하는 일 |
|---|---|
| 호스트 | 사진 업로드 → 메뉴 확인/수정 → 타이머(분) 설정 → **주문 시작하고 공유하기** → 링크 전달 |
| 참여자 | 링크 접속 → 메뉴 수량 선택(내 금액 실시간 표시) → 이름 입력 → **주문 제출** (재제출 시 갱신) |
| 모두 | 전체 주문 현황과 **전체 총 금액**을 실시간으로 확인 |
| 마감 | 타이머 종료 시 접속 중이던 모든 화면에 **최종 주문 결과**(메뉴별 합계 · 사람별 내역 · 총 금액) 표시. 방 데이터는 정리되어 이후 링크로는 접속 불가 |

## 주의 사항

- Anthropic API 키는 브라우저에서 직접 API를 호출하는 방식이므로 **개인/팀 내부 용도**로만 사용하세요. 공개 서비스로 운영하려면 서버(프록시)를 두고 키를 숨겨야 합니다.
- Firebase 테스트 모드 규칙은 누구나 읽고 쓸 수 있으므로, 장기 운영 시 규칙을 강화하세요.
